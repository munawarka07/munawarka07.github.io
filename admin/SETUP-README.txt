What this package does
----------------------
1. Keeps the public UAE Labour Law URL unchanged:
   https://munawar.in/hr-hub/uae-labour-law/
2. Keeps the public page statically generated by GitHub Pages/Jekyll for SEO.
3. Stores editable Labour Law cards in _data/labour_law.yml.
4. Adds /admin/ with Decap CMS.
5. /admin/ is noindex and blocked in robots.txt; it is not linked from the public site.
6. GitHub OAuth is handled by the Cloudflare Worker. No GitHub secret is stored in the website.
7. The OAuth Worker restricts successful login to GitHub user munawarka07.

--------------------------
https://munawar.in/admin/

---------------
Keep your original ZIP as a rollback copy. GitHub also stores every CMS update as a commit.
